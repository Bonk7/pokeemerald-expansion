# Wild Encounters export

Deze map bevat een herhaalbare workflow voor het genereren van twee markdown-documenten uit [src/data/wild_encounters.json](../../src/data/wild_encounters.json).

## Herhalen

Voer één van deze commands uit vanuit de repository-root:

```bash
python3 "Change Frank/wild_encounters_export/generate_wild_encounters_docs.py"
```

of:

```bash
bash "Change Frank/wild_encounters_export/run.sh"
```

De bestanden worden automatisch bijgewerkt in deze map:

- wild_encounters_unique_pokemon.md
- wild_encounters_locaties.md
